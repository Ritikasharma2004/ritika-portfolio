Eight projects, written up properly

Each write-up covers the same ground: the question, the data quality work that came before the analysis, the findings with the actual numbers, and an honest account of what the data could not support. Several of these projects reached a negative result — those are included in full, because knowing which questions a dataset cannot answer is most of the job.

A note on the negative results

Four of these eight projects report that the obvious analysis does not hold up: a forecasting study where the baseline wins, an A/B test where the famous null result is unmeasurable, a customer dataset that cannot answer its own business question, and an attrition driver that turns out to be an artifact of how the file was built. Each one is reported with the specific number that shows why. A result that says "this does not work, and here is the measurement that proves it" is more useful to a business than a confident chart built on a confound.
